## 🌟 About The Project

**EIGHTEEN — The Era of Kohli** is a cinematic, interactive web experience created as a digital museum dedicated to the cricketing journey of Virat Kohli.

Instead of presenting a conventional biography or statistics page, the project is designed as an **interactive documentary experience**.

The website combines:

- 📖 Career storytelling
- 📊 Interactive statistics
- 🏆 Records and milestones
- 🎬 Cinematic match moments
- 🎮 Interactive cricket experiences
- 🧠 AI-powered career assistant
- 👑 Personalized fan identity
- 🔊 Procedural atmospheric sound
- 🎨 Dark / Lite visual modes
- ⚡ Interactive animations and transitions
- 🎉 Celebration effects and Easter eggs

The central philosophy of the project is simple:

> **Numbers tell the career. Moments tell the story. Mindset creates the legacy.**

## 🚀 Run the Project Locally

### 1. Prerequisites

Before running EIGHTEEN, make sure you have installed:

* **Node.js 20 or higher**
* **npm**
* **Git** *(only required if cloning the repository)*

Check your installation:

```bash
node --version
npm --version
git --version
```

---

### 2. Clone the Repository

```bash
git clone https://github.com/JayeshGujar327/EIGHTEEN-the-era-of-kohli.git
```

Move into the project:

```bash
cd EIGHTEEN-the-era-of-kohli
```

---

### 3. Install Dependencies

Run:

```bash
npm install
```

This installs all required packages from `package.json`.

---

### 4. Configure Environment Variables

If you want to use the **Kohli AI Assistant**, create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

> The AI assistant requires a valid Gemini API key.
> Never commit your real API key to GitHub.

If you only want to explore the main website, you can run the project without configuring the AI API.

---

### 5. Start the Development Server

Run:

```bash
npm run dev
```

The application will start at:

```text
http://localhost:3000
```

Open that URL in your browser.

---

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

After a successful build, the production files are generated inside:

```text
dist/
```

---

## 👀 Preview the Production Build

To preview the production build locally:

```bash

```

Because the project is configured for GitHub Pages, Vite may display:

```text
http://localhost:4173/EIGHTEEN-the-era-of-kohli/
```

Open the exact URL shown by the terminal.
